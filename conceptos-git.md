# conceptos basicos de git

- **repositorio**: carpeta controlada por git -> la version final guardada
- **commit**:foto del momento de tu proyecto con un mensaje, que hiciste aca
- **staging area**: Zona de preparacion
- **branch**: rama de trabajo de linea de tiempo alternativa
- **merge**: cuando unes varias ramas en una
- **working directory**: donde editamos nuestros archivos
